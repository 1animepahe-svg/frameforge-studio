04 / LEARN

The short version.

From your editor to a playback-ready file, in a few straightforward steps.

01

Export your source

Use a compatible MP4 or MOV, up to 200 MiB. Keep the original file as a backup. The tool supports a conservative subset of common H.264/H.265 or MPEG-4 video and AAC audio containers.

02

Choose & inspect

Open Enhancer and select a local file. Analytics shows details your browser can read. Browser codec support varies, so previews or metadata may not always be available.

03

Optimize & review

Run the optimizer, then use Compare to preview both versions. If metadata is already before the media, the original file is offered unchanged.

04

Download your copy

Save the output and check it in your intended player. Fast-start can help progressive playback; social platforms can still re-encode uploads.

ⓘ

Fragmented files, external media references, unsupported boxes and unsafe or malformed structures are rejected rather than guessed at.

05 / QUESTIONS

Good questions.

Honest answers about what this little tool can and cannot do.

What does fast-start actually do?

It moves the movie metadata box (moov) ahead of the media data (mdat), updating chunk offsets. This can let compatible players begin progressive playback sooner.

Does it improve quality or bypass compression?

No. It does not change the encoded video or audio and cannot prevent platforms from recompressing an upload. It makes no promises about quality or engagement.

Why was my file rejected?

The parser intentionally accepts a limited set of box types and self-contained layouts. Fragmented, extended-size, unusual, malformed, external-reference, or otherwise unsupported files are rejected to avoid unsafe output.

What if my file is already optimized?

The original is offered for download unchanged, with an explicit notice. It is not re-encoded.

Does this support TikTok URLs or analytics?

No. It only reads files you select locally. It cannot download remote videos or access TikTok views, engagement, or accounts.

Is there a charge or account?

No accounts, payments, or subscriptions. The files are processed in your browser, up to 200 MiB per file.

06 / YOUR DATA

Privacy, plainly.

The important part: your video stays with you.

No file uploads

The optimizer, metadata inspection and preview run locally in your browser. This app does not send your chosen file, metadata, or output to a server.

Temporary session

Your selection and previews exist in memory until you remove them, refresh, or close the page. Downloaded files remain wherever you save them. No account or local history is created.

Hosting still serves the app

If hosted on GitHub Pages, your browser requests the app files from GitHub, whose normal hosting logs and policies may apply. This project includes no analytics, advertising, third-party scripts or external assets.
